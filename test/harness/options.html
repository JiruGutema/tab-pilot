Tab Pilot

Open Tab Pilot

Global shortcut that opens the search popup from anywhere in Firefox.

Firefox reserves some shortcuts for itself (for example CtrlT, CtrlW). You can also manage all extension shortcuts at about:addons → ⚙ → Manage Extension Shortcuts.

Keyboard (inside the popup)

Click + and press a key combination to add a binding. Each action can have several.

Tip: if a binding such as CtrlN opens a new Firefox window instead of moving the selection on your system, Firefox is treating it as a reserved shortcut — use the CtrlJ/CtrlK alternatives or bind your own.

Backup & reset

Settings sync across devices through your Firefox account when sync is enabled.
